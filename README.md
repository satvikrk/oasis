OASIS is a full-stack music streaming service designed to simulate the core functionality of modern digital streaming platforms. The system integrates a structured relational database with a backend service and a user-facing frontend to manage music data, user interactions, and playback-related operations.
The project focuses on database-driven application design, demonstrating how large collections of media content can be organised, queried, and served efficiently using SQL. It models real-world streaming platform features such as user accounts, song libraries, playlists, and content management through a structured schema and query workflows.


Architecture:

The system follows a layered architecture:
Database Layer — Relational schema designed using SQL to manage songs, users, playlists, and metadata. Includes scripts for schema creation and data population.
Backend Layer — Handles application logic, data retrieval, and interaction between the frontend and database.
Frontend Layer — Provides a user interface for browsing content and interacting with the streaming system.
This separation ensures modularity, maintainability, and scalability.


Key Features:

Structured relational database design for music streaming workflows
SQL scripts for schema creation and data insertion
Backend integration for database communication and query handling
Frontend interface for content interaction
End-to-end full-stack implementation
Demonstrates database normalisation and efficient query design


Learning Objectives:

This project was built to explore:
Database schema modelling for real-world applications
Full-stack system integration
SQL query design and optimisation
Data-driven application architecture
Practical implementation of CRUD operations


Technology Stack:

SQL (database design and querying)
Python (backend logic)
JavaScript / frontend technologies (UI)

Summary:

OASIS demonstrates how relational databases power content-heavy platforms such as music streaming services. It provides a complete workflow from data modelling to user interaction, highlighting the role of structured storage, query processing, and full-stack integration in building scalable digital applications.
